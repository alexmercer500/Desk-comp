# Current builds

The latest installable builds, replaced whenever a fix needs new ones. They are built by the same release script as
what gets published on https://github.com/alexmercer500/Desk-comp-releases/releases, so these copies update
themselves from there.

| File | What |
| --- | --- |
| `DeskCompanion_0.15.1_x64-setup.exe` | Windows app 0.15.1 (relay built in, checks for updates). Not code-signed yet: Windows may warn, choose More info, Run anyway. |
| `DeskCompanion-Android-0.5.1.apk` | Android app 0.5.1, signed with the release key (checks for updates). Phones with the older debug-signed 0.3.x must uninstall it once and pair again. |

What changed in each: `CHANGELOG.md`. How releases are made: `docs/RELEASING.md`.
