    Leave the desk. Take the OK with you.

    The Android app shows your agents, lets you Allow or Deny, and can reply to an agent that finished. It pairs with your PC over your own Wi-Fi or your phone's hotspot.

    Away from home, it can go through a relay you run yourself on Cloudflare's free plan, encrypted end to end. The app walks you through setting one up.

    Yours, and only yours.

    • No account Install it and it's yours.
    • No telemetry Nothing about you leaves your PC.
    • Runs on your PC Agent events stay on a local pipe only you can write to.
    • Your click only Every Allow is yours to give.
    • MIT licensed Read every line, change anything.

    Stick it on in a minute.

    1. Download The installer is about 5 MB and installs for you only, no admin rights.
    2. Run it, even if Windows frowns Kulhi isn't code-signed yet, so Windows may say it protected your PC. Choose More info, then Run anyway.
    3. Connect your agents Settings → Coding agents. One switch each; turning it off takes the hooks out again.
    Mac or Linux?

    Windows only for now. Linux is planned.

    Will it slow my PC down?

    The 2D characters are light. Rui is in 3D; on a laptop he can hand over to a 2D friend while you're on battery.

    How do updates work?

    It checks GitHub every few hours. Updates are signed, and install only when you click.

    Does it cost anything?

    No. It's free and open source under the MIT licence. The optional Ask feature uses your own Anthropic API key.

    How do I remove it?

    Uninstall it from Windows Settings. That takes out its hooks too, after backing up your agents' settings.
